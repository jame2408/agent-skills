# Learning Context Template

每次開發迴圈的 Phase 4 完成後，依此範本產出學習筆記。此筆記將作為下一輪迴圈 Phase 1 的 Context 輸入。

## 格式

```markdown
# 學習筆記 — [功能名稱] ([日期])

## 迴圈摘要
- 實例化需求：[一句話描述本次需求]
- 影響範圍：[修改的模組/檔案]

## 架構理解
- [對系統架構的新發現或確認]

## 需求澄清
- [需求理解過程中的偏差與校正]

## 技術決策
- 決策：[做了什麼決定]
- 原因：[為什麼這樣決定]
- 取捨：[放棄了什麼替代方案]

## 問題與解決
- 問題：[遭遇的問題]
- 解決：[如何解決]
- 預防：[未來如何避免]

## 可複用模式
- [本次開發中發現的可複用模式或解法]

## 下輪建議
- [對下一個開發迴圈的建議或注意事項]
```

## 使用方式

1. Phase 4 完成時，依上述格式填寫學習筆記
2. 若使用者有下一個需求，將此筆記附加到下一輪 Phase 1 的 Context 中
3. 多輪迴圈的學習筆記可累積，形成專案知識庫
